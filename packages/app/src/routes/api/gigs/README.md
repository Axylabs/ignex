# Gig resource

Generated by `ignex resource gig`. CRUD routes under `/api/gigs`:

- `GET    /api/gigs`        — list (paginateFlexible, `page`/`limit` query)
- `GET    /api/gigs/:id`    — read one (getOne)
- `POST   /api/gigs`        — create (insertOne)
- `PATCH  /api/gigs/:id`    — update (updateOne)
- `DELETE /api/gigs/:id`    — delete (deleteOne)

`:id` params are schema-validated (malformed ids → 422) and missing docs throw a
404. Edit `src/models/gigs.ts` to change the schema, then run:
```sh
bunx ignex db:sync
```
